# 🎈 بالونات حرف الباء

لعبة تعليمية للأطفال للتمييز البصري والصوتي لحرف الباء (ب) في بداية الكلمة.

## الملفات
- `index.html`: اللعبة كاملة في ملف واحد، ولا تحتاج أي مكتبات أو إنترنت.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على github.com بصيغة Public.
2. ارفع الملفين `index.html` و `README.md` (Add file ← Upload files).
3. من **Settings ← Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة أو دقيقتين يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`
